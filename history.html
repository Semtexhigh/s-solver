README

S Solver — complete version history

43 builds, v3.3 to v5.25, oldest to newest, from 2026-09-30 to 2026-11-11.

Each build is the whole extension as one readable text bundle (manifest, background worker and every site engine), plus a zip of its full source folder. The newest build also has the Chrome Web Store package. The OCR files that every build shares are kept once, as tesseract.zip.

The Modules tab splits the latest build into 52 parts — the engine for each website, the shared core, the panel and popup, and every panel animation with a live preview — each encrypted on its own.
