Get an API key for S Solver

An API key lets S Solver use a proper AI to work out questions. Gemini and Groq are free and don't need a card. Pick one below, follow the steps, then paste the key into S Solver.

Free Gemini key

Google AI Studio gives you a free key. You only need a Google account.

  1. Open Google AI Studio's key page

    Sign in with your Google account if it asks.

    Open aistudio.google.com/apikey ↗

  2. Accept the terms (first time only)

    Tick the boxes and press Continue.

  3. Press "Create API key"

    If it asks for a project, pick the one it suggests or press "Create project".

    API keysCreate API key

  4. Copy the key

    It starts with AIza. Press the copy button next to it.

    AIzaSy••••••••••••••••••••••Copy

  5. Paste it into S Solver

    See Add it to S Solver. Pick a Gemini model there.

The free plan has a daily limit. If S Solver says "rate limit", wait a minute or switch to Gemini Flash-Lite, which has the highest free limit.

Free Groq key

Groq is free and very fast. It only reads text, so questions with a picture still need Gemini or Claude.

  1. Open the Groq console

    Sign up with Google, GitHub or an email address.

    Open console.groq.com/keys ↗

  2. Press "Create API Key"

    Type any name, for example S Solver, then press Submit.

    API KeysCreate API Key

  3. Copy the key straight away

    It starts with gsk_. Groq only shows it once. If you lose it, make a new one.

    gsk_••••••••••••••••••••••••Copy

  4. Paste it into S Solver

    See Add it to S Solver. Pick Groq as the model.

Claude key (paid)

Claude is very accurate, including with diagrams. It isn't free: you add credit first, then each question costs a fraction of a cent.

  1. Open the Claude Console

    Create an account or sign in.

    Open the Claude Console ↗

  2. Add credit

    Go to Billing and buy a small amount of credit. A card is needed.

  3. Create a key

    Go to API keys and press Create key. Give it a name such as S Solver.

    API keysCreate key

  4. Copy the key straight away

    It starts with sk-ant- and is only shown once.

    sk-ant-••••••••••••••••••••••Copy

  5. Paste it into S Solver

    See Add it to S Solver. Pick Claude Haiku (cheaper) or Claude Sonnet.

Set a monthly spending limit in the Console so it can never cost more than you expect.

Add the key to S Solver

You only do this once. The key stays on your computer.

  1. Click the S Solver icon in Chrome's toolbar

    If you can't see it, click the puzzle-piece icon and pin S Solver.

  2. Paste your key into the API key box

    gsk_ / sk-ant- / AIza...

  3. Choose the model that matches your key

    Gemini key → a Gemini model. Groq key → Groq. Claude key → Claude Haiku or Sonnet.

  4. Press "Save and Activate"

    Go back to your homework tab. There's no need to refresh.

    ReadySave and Activate

Questions

Do I need a key at all?

No. Without one, S Solver still uses its own built-in solver and a free web answer. A key makes it faster and better at harder questions and diagrams.

Is my key safe?

S Solver keeps the key in your browser and only sends it to the AI company you picked. Don't share it or post it anywhere. If someone gets it, delete it on the same page you made it and make a new one.

It says the key is wrong

Check you copied the whole key with no space at the start or end, and that the model matches the key (a Gemini key needs a Gemini model).

It says "rate limit" or "quota"

Free keys allow a set number of questions per minute and per day. Wait a minute, set a longer time per question, or switch to Gemini Flash-Lite.
